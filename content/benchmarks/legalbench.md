LegalBench groups tasks by the reasoning they call for. Issue spotting asks whether a fact pattern raises a legal issue. Rule application tests whether a model can use a rule on a particular set of facts. Pick the reasoning skill first, then inspect the individual task’s examples and evaluation procedure. [Task index](https://hazyresearch.stanford.edu/legalbench/tasks/)

**What you can run.** The maintainers publish task data and prompt templates. Each task has its own terms, which matter if you plan to redistribute its examples. When reporting a result, include the task and prompt so another reader can identify the exercise. [Getting started](https://hazyresearch.stanford.edu/legalbench/getting-started/) · [Repository and task licenses](https://github.com/HazyResearch/legalbench)
