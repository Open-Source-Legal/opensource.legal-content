# Open Source Legal content

Edit [the tool directory](oss_directory.json), add [a how-to article](content/articles/), or [propose a blog post](CONTRIBUTING.md#write-a-blog-post). Contributors can propose changes from a fork. Read the [contribution instructions](CONTRIBUTING.md) and the [contributor license agreement](CLA.md).

Reviewed merges publish articles, blog posts, directory data and search listings to [opensource.legal](https://opensource.legal/). Original editorial content is available under [Creative Commons Attribution–NonCommercial 4.0 International](https://creativecommons.org/licenses/by-nc/4.0/). Linked projects retain their own licenses.
