# Open Source Legal content

Edit [the tool directory](oss_directory.json) or add a Markdown post to [the article folder](content/articles/). Contributors can propose changes from a fork. Read the [contribution instructions](CONTRIBUTING.md) and the [contributor license agreement](CLA.md).

Reviewed merges publish articles, directory data and search listings to [opensource.legal](https://opensource.legal/). Original editorial content is available under [Creative Commons Attribution–NonCommercial 4.0 International](https://creativecommons.org/licenses/by-nc/4.0/). Linked projects retain their own licenses.
